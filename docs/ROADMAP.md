# Roadmap — Features After Phase 1

Phase 1 is designed so these can be added later without rebuilding the core (every expense already has project + head + sub-head).

## Phase 2 — Control & labour
- Budget per project **per head**, alerts at 80% / 100%, optional block or extra approval
- Multi-level approval rules by amount and head; Project Manager role
- Labour attendance per site with automatic wage calculation
- Advance balance tracking and recovery from wages
- Printable weekly/monthly wage sheets
- Petty cash per site in-charge (cash given vs spent, balance in hand)
- Import from existing Excel sheets

## Phase 3 — Purchasing & travel
- Purchase request → approval → purchase order → GRN → bill
- Vendor payables, partial/advance payments, ageing
- Basic inventory per site and material transfers between projects
- Travel requests, travel advances and settlement
- TA/DA policy (DA rate by grade/city, mileage) with automatic calculation
- Claim workflow Submitted → Approved → Paid; Employee role

## Phase 4 — Full accounting
- Chart of accounts and automatic double-entry journals
- Cash book, bank book, bank reconciliation
- Client invoices / running bills and receipts, project profitability
- GST / sales tax and withholding tax
- Trial balance, P&L, balance sheet, cash flow
- Financial year closing, period locking, multi-company

## Add-ons (any time)
- Mobile app with receipt camera, GPS/QR attendance
- WhatsApp / SMS / email alerts
- OCR receipt reading
- Asset & vehicle register
- Urdu interface
